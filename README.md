# Excel Planning Uploader Pro (SAP Analytics Cloud)

> Enterprise-grade custom web component for SAP Analytics Cloud (SAC) featuring visual Full/Delta load strategy cards, DSP Artifact toggle, interactive multi-sheet consolidation, multi-severity validation rules with configurable semaphores (🟢🟡🔴🟣), workbook-scoped rules & temporal validity windows, Assisted Code Formulas & Auto-Fix (`✨`), configurable file format & delimiter, drill-down Audit Monitor with customizable exports, built-in interactive Help Guide (`? Help`), and SAP Fiori Horizon UX.

## Key Capabilities

* **Visual Full vs. Delta Load Strategy & DSP Artifact Switch**: Choose between complete model replacement (`FULL LOAD`) or incremental adjustments (`DELTA LOAD`) with Fiori segmented cards and toggle switches, tracked in the SAC payload and audit history.
* **Semaphores, Scoped Rules, Rule Cloning & Temporal Validity**: Assign color semaphores to alerts, clone rules (`📋 Clone`), restrict rules to specific workbook names (`scopeFiles`) or date ranges (`startDate` / `endDate`), and edit scopes inline without browser popups.
* **Configurable Audit Monitor & Custom Exports**: Inspect committed data snapshots, load strategies, active rules, and cell edits, and export custom `.xlsx` or `.csv` audit reports selecting exact column counts, comments, and audit trails.
* **Built-In Interactive Help Guide (`? Help`)**: Comprehensive step-by-step documentation overlay inside the widget.
