# Excel Planning Uploader Pro (SAP Analytics Cloud BTP)

> Enterprise-grade custom web component for SAP Analytics Cloud (SAC) featuring multi-file & interactive multi-sheet consolidation, customizable validation rules engine, configurable file format & delimiter (tabulador), drill-down BTP Audit Monitor, and SAP Fiori Horizon UX.

## Key Capabilities

* **Visual Validation Rules Engine (`⚙️ Validation Rules`)**: Create, toggle, and delete custom validation rules per column in real time (`IN_LIST` Master Data, `NUMERIC_RANGE`, `STARTS_WITH`, `REGEX`, and `UNIQUE`).
* **Interactive Multi-File & Sheet Selector**: Load multiple `.xlsx`, `.xls`, `.csv`, or `.txt` files simultaneously or incrementally, and check/uncheck which individual sheets (pestañas) inside each workbook to consolidate.
* **Configurable Format, Tabulador & Number Normalization**: Choose file format, delimiter (`Auto`, `TAB \t`, `;`, `,`, `|`), header row offset, and automatic European decimal conversion (`1.234,56` → `1234.56`).
* **Interactive Drill-Down BTP Audit Monitor**: Click any load execution (`LOAD-XXXXX`) to inspect the committed data snapshot, cell-by-cell modification history (`Previous Value → New Value`), selected sheets metadata, and raw SAC JSON payload.
