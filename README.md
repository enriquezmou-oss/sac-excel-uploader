# Excel Planning Uploader Pro (SAP Analytics Cloud)

> Enterprise-grade custom web component for SAP Analytics Cloud (SAC) featuring Full/Delta load strategy, interactive multi-sheet consolidation, multi-severity validation rules with semaphores (🟢🟡🔴🟣), scoped rules & temporal validity windows, Assisted Code Formulas & Auto-Fix (`✨`), configurable file format & tabulador, drill-down Audit Monitor with customizable exports, built-in interactive Help Guide (`? Help`), and SAP Fiori Horizon UX.

## Key Capabilities

* **Full vs. Delta Load Strategy**: Choose between complete model replacement (`FULL`) or incremental adjustments (`DELTA`), tracked in payload and audit history.
* **Semaphores, Scoped Rules & Temporal Validity**: Assign color semaphores to alerts, restrict rules to specific workbook names (`scopeFiles`) or date ranges (`startDate` / `endDate`), and copy rules across files.
* **Configurable Audit Monitor & Custom Exports**: Inspect committed data snapshots, load strategies, and cell edits, and export custom `.xlsx` or `.csv` audit reports selecting exact columns, comments, and audit trails.
* **Built-In Interactive Help Guide (`? Help`)**: Comprehensive step-by-step documentation overlay inside the widget.
